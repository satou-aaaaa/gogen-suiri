# 語源すいり

英単語をパーツ（前につくもの・まん中・うしろにつくもの）に分けて、パーツの意味から単語の意味を推理する1日5問のゲーム。英語を知らなくても、パーツの意味をつなげれば答えにたどり着けます。

- 遊ぶ: https://satou-aaaaa.github.io/gogen-suiri/
- 今日の5問（意味あて2・組み立て2・見やぶり1）はだれでも同じで1日1回。上級（見やぶり3問・ヒントなし）、練習（何度でも）、とことん（何問続けて一度で解けるか）、集めたパーツと単語が並ぶ「パーツ帳」があります。
- 正解すると「tele（遠く）＋ scope（見る）＝ 遠くを見るもの」のような答え合わせが出ます。ヒントは「見るところ」→「選び肢を2つにしぼる」の2段です。
- パーツの札は、生まれた言葉（ギリシャ語・ラテン語など）で色と字が分かれます。
- 文字の大きさは3段。見やすさの設定（読みやすい文字・色の見分け・動きを減らす・読み上げ）もあります。
- 機種を変えるときは「引き継ぎ」で、記録をコードと QR にして移せます。

## 語源の出どころと研究

- 単語の語源は [Online Etymology Dictionary](https://www.etymonline.com/)（Douglas Harper）で確かめています。パーツの意味は、だれにでも分かるように短く言いかえています。
- 単語のつくり（形態素）に目を向ける学び方は、語いと読みの助けになると報告されています（[Bowers ほか 2010](https://doi.org/10.3102/0034654309359353)・[Goodwin & Ahn 2013](https://doi.org/10.1007/s11881-013-0068-1)）。思い出して答える練習は読み直すより記憶に残りやすいことも知られています（[Adesope ほか 2017](https://doi.org/10.3102/0034654316689306)）。

## 記録と通信

記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、まだ端末に保存が無ければ Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（単語と答えは入りません）。英語の読み上げは端末の中の声だけを使います。
